Personal job-search tool

Job Hunter Agent

Job Hunter Agent collects job opportunities, compares them with a configured candidate profile, and sends a daily email brief.

How it works

The tool runs in Google Apps Script. It reads job alerts and forwarded job leads from the authorized Gmail account. It also checks configured public career sites and job feeds. It stores job records, profile settings, source health, and delivery history in a Google spreadsheet.

Matching rules rank jobs against the configured profile. Optional Groq summaries explain selected matches using job text and a limited candidate profile excerpt. AI summaries do not set the match score.

Google account access

Google authorization allows the tool to read relevant email, use its bound spreadsheet, send reports to the configured recipient, and run scheduled tasks. The tool is operated for personal use. This website does not provide public registration or access to the tool.
